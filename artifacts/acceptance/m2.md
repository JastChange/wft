# WFT 1.0 M2 验收证据

## 范围与环境

M2 交付手动任务创建、AsyncSSH/SFTP 执行、状态/结论/退出码、权威文件存储、取消/残留处理以及任务 CLI。日期为 2026-08-07，验证环境为 Python 3.12；CI 矩阵为 Ubuntu 24.04 与 macOS 14。

SSH 证据来自进程内 AsyncSSH 回环服务器，验证协议适配、密钥认证、SFTP、原始字节、超时信号和清理路径；它不是实际生产节点认证。

## 补充门禁

- UUIDv7、冻结模型、时间戳和结果不变量：`tests/tasks/test_models.py`；
- 非 UTF-8、增量 SHA-256、无限原始流基础：`tests/storage/test_raw_streams.py`；
- ENOSPC 拒绝新任务且不删除历史：`tests/storage/test_storage_failures.py::test_storage_probe_prevents_publication_without_deleting_history`；
- 安全删除、拒绝 symlink、无 tombstone/reason：`tests/storage/test_delete.py`；
- M2 不暴露 scheduler/resume/retry/Web/analyze/export/index：`tests/cli/test_m2_commands.py::test_m2_help_has_no_future_commands`。

## 已接受但未执行的发布测试

M2 不把真实磁盘填满、kill -9、真实 Ubuntu 节点认证和超大输出压力作为发布门禁。采用确定性 ENOSPC 注入、常规 asyncio 取消和回环 SSH 集成；对应运行风险按 ADR-0006 接受。M2 也没有 Scheduler、resume、backup、migration、SQLite 权威性或 Web 写操作。
