## 计划修正与边界

- 按 AC-001，节点私钥相对路径被拒绝，而不是按早期 M1 草案自动转为绝对路径。
- Deploy Key 路径必须为绝对路径且文件为 `0600`，并实际传入 Git/SSH adapter。
- 增加 `types-PyYAML`，保持严格 mypy，不通过关闭检查规避类型错误。
- 保留的 M2 HTTP/SSH 测试桩位于 `tests/support/`，不参与 M1 Ruff；M2 引入 AsyncSSH 后再启用。
- AC-002 的 Cookie 和 AC-004 的任务级全节点一致性没有在 M1 冒充完成，分别在 M3、M2 验收。
- 旧 MVP contracts、runtime、tests、内置脚本注册表示例和内置示例脚本已删除；外部 Git Manifest 是唯一脚本来源。
